# 缓存 + 设置菜单 设计

Date: 2026-05-08 | App: EroMusicSearch v1.4.0

## 一、缓存功能

**策略：** 缓存优先 + 后台刷新，永不过期，手动清除

**工作流：**
1. 搜索 → 立即显示缓存结果（如有）→ 后台请求网络
2. 网络成功 → 更新缓存 → 刷新 UI
3. 网络失败 + 有缓存 → 保持缓存显示，不报错
4. 无缓存 + 网络失败 → 显示错误（现有行为）

**缓存键：** `source|mode|term|mirrorMode`

**存储：** `{userData}/search-cache.json`

**UI 指示：** 命中缓存时表格上方显示 `キャッシュから表示（更新中...）`

---

## 二、设置菜单

工具栏右侧 ⚙ 图标，点击弹出暗色下拉菜单。

**菜单项目：**

| 分类 | 项目 | 类型 |
|------|------|------|
| 搜索 | 既定のデータソース | 下拉 (EGS / Bangumi / Anison.info) |
| 搜索 | 既定の検索方向 | 下拉 (作品→音楽 / 音楽→作品) |
| 搜索 | CNミラーを既定でON | 复选框 |
| 外观 | フォントサイズ | 下拉 (S=12px / M=13px / L=14px) |
| 外观 | ウィンドウサイズ | 下拉 (800x600 / 900x700 / 1024x768) |
| 缓存 | キャッシュを削除 | 按钮 (显示缓存条数) |

**存储：** `{userData}/settings.json`
